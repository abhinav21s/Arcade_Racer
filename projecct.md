# Neon Arcade Racer – Overview

## What is this project?
Neon Arcade Racer is a fast-paced, neon-styled browser racing game built with Phaser 3 and TypeScript. It features a pseudo-3D road, tight arcade controls, drifting, boosts, score chasing, and unlockable cars.

## Current Status
- Players can start a race and drive
- Score-based car unlock system is working
- Basic menu, car selection, and high-score display exist
- Core driving loop is playable

## Tech Stack
- Phaser 3
- TypeScript
- Vite
- Deployed on Vercel

## Core Fantasy
Fly through a glowing neon city at high speed, chain drifts and near-misses, collect power-ups, and push for the highest score while unlocking new rides.

## Current Features
- Title / car select screen
- One unlocked car + locked cars with score requirements
- Start race
- Driving with keyboard (Arrows / WASD)
- Drift (Space / Shift)
- Boost (E)
- Score accumulation
- Car unlock on reaching score thresholds (10k, 25k, 50k, 100k)
- Basic high-score area on menu

## Goal
Turn this into a polished, juicy, addictive arcade racer with strong game feel, visual effects, power-ups, and replayability.
